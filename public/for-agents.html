For agents

Discovery and control notes for draw, a client-only whiteboard at draw.marcopontili.com.

How to use the app

  1. Open the live app (or local Vite on port 5173).
  2. Wait until window.draw exists.
  3. await window.draw.setScene(json): .excalidraw JSON string with type: "excalidraw" and an elements array, max 20 MB. Replaces the canvas.
  4. window.draw.getScene(): the current scene as .excalidraw JSON.
  5. await window.draw.exportImage("png") returns a data URL; "svg" returns SVG markup. Both throw on an empty canvas.

Coding-agent procedure: draw-scene skill.
